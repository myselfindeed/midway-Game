## 2. 关卡 3「勇敢的诱饵」

**史实**：中途岛海战中，美军舰载鱼雷机队（尤以 VT-8 中队）几乎全灭，却把日军战斗机与防空火力牢牢牵制住，为随后俯冲轰炸机的致命一击创造了窗口。

**玩法**：玩家单机扮演"诱饵"，在敌机群持续围攻下坚持到倒计时结束。

| 项 | 建议值 |
|----|--------|
| 目标 | 存活 90 秒（倒计时结束即胜） |
| 阶段 A | 0–45s：敌机波次，同屏 ≤4 架（28 血），每 12s 补满到 4 架 |
| 检查点 cp1 | 45s 存活 |
| 阶段 B | 45–90s：敌机升级 36 血，补兵间隔缩短到 9s，同屏 ≤4 |
| 失败 | 玩家被击落 |
| 可选副目标 | 全程击落 ≥ 8 架（是否作为"牵制达标"见待确认 Q1） |

**HUD**：`missionText` 显示倒计时（如 `牵制敌机 0:45`），`phaseText` 显示击落数与阶段。
**旁白开场**（3 句）：① 1942 年 6 月 4 日，鱼雷机群贴着海面扑向日军舰队。② 它们一架接一架坠落，却把敌人的战斗机全都拽了下来。③ 任务：牵制来袭敌机，撑过最危险的一刻，直到友军俯冲轰炸机赶到。
**结算收束**：历史收束——那些坠入海中的鱼雷机，为"决定性的五分钟"买下了入场券。

**复用清单**：`spawnWave`（intercept 敌机）、计时 `elapsed`、检查点满血重置。

## 3. 关卡 4「决定性的五分钟」

**史实**：6 月 4 日上午 10:20 前后，美军 SBD 俯冲轰炸机在短短数分钟内命中"赤城""加贺""苍龙"三舰，一举扭转战局。

**玩法**：突破敌军护航，俯冲打击航母。

| 项 | 建议值 |
|----|--------|
| 阶段 A · 突破护航 | 击落 6 架护航敌机（28 血）；同屏 ≤5 架 |
| 检查点 cp1 | 阶段 A 达成 |
| 阶段 B · 俯冲打击 | 击沉敌航母（建议 500 血）+ 击沉 1 艘护航驱逐舰（160 血）；航母持续 AA（沿用关 1 参数） |
| 敌航母产敌机 | **要产**：阶段 B 起，航母每 9s 产 1 架护航机（从航母上空起飞），单舰护航机上限 3 架，全局敌机 ≤6；击沉航母后停产 |
| 失败 | 玩家被击落（可选：倒计时 180s 超时，见 Q4） |

**数值说明**：航母 500 血 ≈ 地狱火 88/发 × 6 发，配合机炮扫射（12/发）与对舰加成收尾；驱逐舰 160 血 = 一发地狱火 + 少量机炮。
**旁白开场**：① 上午 10 点，日军航母甲板上堆满了换挂弹药的飞机。② 这就是历史上那个"决定性的五分钟"——五分钟后，三艘航母都将燃起大火。③ 任务：突破护航，俯冲命中敌方主力航母。
**结算收束**：历史收束——五分钟的决断，让太平洋战局在一日之间易手。

**复用清单**：敌 `createCarrier`（对舰加成 1.6）、`createDestroyer`、护航敌机 `spawnWave`。

## 4. 关卡 5「最后的反击」

**史实**：当日傍晚，日军最后一艘主力航母"飞龙"被击沉，中途岛海战基本结束。

**玩法**：清剿残存航母群，全部击沉。

| 项 | 建议值 |
|----|--------|
| 目标 | 击沉 2 艘航母（各 400 血）+ 2 艘驱逐舰（各 160 血） |
| 敌机 | 持续来袭护航，同屏 ≤4 架（36 血） |
| 航母产敌机 | 两艘航母各每 12s 产 1 架（单舰上限 2，全局敌机 ≤6）；击沉即停 |
| 检查点 cp1 | 击沉第一艘航母 |
| 失败 | 玩家被击落（可选：倒计时 240s 超时，见 Q4） |

**旁白开场**：① 夕阳西下，日军最后一艘航母仍在海面上。② 它是这场海战最后的抵抗——击沉它，中途岛就彻底安静下来。③ 任务：清剿残余航母群，一个都不能留。
**结算收束**：历史收束——太平洋的天空重新安静下来，中途岛守住了。

**复用清单**：敌 `createCarrier` ×2、`createDestroyer` ×2、护航敌机 `spawnWave`。峰值实体：玩家 1 + 敌机 4 + 驱逐舰 2 + 航母 2 = 9 ≤ 12 ✓

## 6. 验收标准（延伸 PRD 5.1）

1. 关卡 3 可完整存活通关 / 失败重试；倒计时清晰。
2. 关卡 4 可"突破护航 → 击沉航母"两步通关，检查点生效。
3. 关卡 5 可清剿 2 航母 + 2 驱逐舰通关。
4. 三关同屏实体 ≤ 12，无新模型/新音效/新画风引入。
5. 关卡 2 通关后顺序解锁 3 → 4 → 5。
