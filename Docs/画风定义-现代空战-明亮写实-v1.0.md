## 0. 一句话定义

**在明亮的正午天空下，驾驶一架金属质感的现代战机，用高饱和的青色能量光效和干净的全息 HUD，打一场看得清的空中街机战。**

三个标签：**明亮（bright）· 干净（clean）· 高能（energetic）**。

反面参照——本作**不是**：
- 不是《中途岛》那种低饱和、灰绿、克制的二战军事写实；
- 不是《皇牌空战》那种电影感暗调、重暗角、胶片颗粒；
- 不是卡通低模 + 厚描边的休闲飞行。

## 1. 从 6 张图读出的共同规范

| # | 截图 | 提供的证据 | 推导出的规范 |
|---|---|---|---|
| 1 | 6406 | 高空云海，双枚导弹白色拖尾横贯全屏，红色菱形敌标 | 云层是"软"的、高亮；拖尾可长至 1.5 倍屏宽 |
| 2 | 6405 | 低空农田 + 远山薄雾，近黑涂装战机，蓝焰 | 强空气透视：远景褪青灰，近景饱和 |
| 3 | 6407 | 云中侧后视，粗白曳光弹道 | 弹道用加法混合的亮白细长条，不做实体模型 |
| 4 | 6408 | 正后追尾视，F-16 单垂尾，喷口巨大青蓝光斑 | 尾焰是画面第一视觉重心，必须 bloom |
| 5 | 6409 | 河谷 + 梯田，同样光斑 | 地形贴图接近航拍/卫星质感 |
| 6 | 6410 | 峡谷近距俯视，翼下挂载可见 | 相机可降到很低，地形起伏必须真实 |

### 1.1 六条硬指标

| 维度 | 规范值 |
|---|---|
| **相机** | 后上方 15°–25°，FOV 42°–48°，翼展占屏宽 **28%–35%** |
| **曝光** | 高调（high key）：整体偏亮，黑位抬到 `#1A2430`，**无死黑、无暗角、无颗粒** |
| **空气透视** | 远景统一褪向 `#A9C6D8`，雾不参与近景（战机 8–12 米内不受雾影响） |
| **材质对比** | 机体哑光金属（粗糙 0.3–0.4）↔ 座舱镜面（粗糙 0.05）↔ 喷口高光金属（粗糙 0.25），三者必须拉开 |
| **光效** | 尾焰核心近白、外焰青蓝，带明显 bloom 溢出；弹道/拖尾用加法混合 |
| **HUD** | 白色 + 青色细线发光，**不用深色底板**，摇杆是直径约屏高 33% 的大圆环 |

### 1.2 画面面积分配（关键认知）

按 6 张图的像素占比估算：

| 层 | 占屏面积 | 说明 |
|---|---|---|
| 天空 + 地形 | **≈ 80%** | 决定整体观感与"贵不贵" |
| 战机 | ≈ 8%–12% | 决定"专不专业" |
| 光效/拖尾 | ≈ 5% | 决定"爽不爽" |
| HUD | ≈ 8% | 决定"像不像手游" |

> **结论：80% 的画面是环境，所以环境的写实度决定一切。**
> 这也是当前项目最大的短板——`yellow-river.jpg` 单张平铺 + 圆形岛屿贴片，在这个画风下会立刻露馅。

## 2. 配色规范

### 2.1 环境

| 用途 | 色值 | 备注 |
|---|---|---|
| 天顶 | `#1E5FA8` | 深蓝，顶部饱和度最高 |
| 地平线 | `#C3DAE7` | 近白青，雾色基准 |
| 云（受光） | `#F7FAFC` | 接近纯白，略偏冷 |
| 云（背光） | `#B9CBD8` | 灰蓝，不做纯灰 |
| 农田（亮） | `#C9BE72` | 麦黄 |
| 农田（绿） | `#9DB35A` | 黄绿，非草绿 |
| 林地 / 灌木 | `#4E6B3A` | 压暗，制造层次 |
| 河流 / 水面 | `#6E8A94` | 灰绿蓝，**不用纯蓝** |
| 道路 | `#D8D2C4` | 浅米，作为地形上的引导线 |
| 远山 | `#8FA0A6` | 已大量混入雾色 |

### 2.2 战机

| 部位 | 色值 | 参数 |
|---|---|---|
| 蒙皮主色 | `#C4C9CF` | metalness 0.45 / roughness 0.35 / clearcoat 0.5 |
| 蒙皮暗部 | `#8C9298` | 用于下表面与阴影区 |
| 座舱盖 | `#101A26` | roughness 0.05，强环境反射 |
| 喷口 | `#6B6259` | metalness 0.9 / roughness 0.25 |
| 敌方涂装 | 深炭灰 `#3A3F45` 或迷彩 | 与玩家浅灰形成明度差 ≥ 3 档 |

### 2.3 光效与 HUD

| 用途 | 色值 | 说明 |
|---|---|---|
| 尾焰核心 | `#F2FBFF` | HDR > 1，负责 bloom 溢出 |
| 尾焰外焰 | `#6FD2FF` → `#2E7BFF` | 渐变，向喷口方向收缩 |
| 尾焰溢光 | `#35C8FF` | 打在机身与地面上的环境光 |

## 3. 光照规范

| 项 | 规范 |
|---|---|
| 时间 | 晴朗正午偏后（太阳高度角约 50°） |
| 主光方向 | 画面左上方 45°，与天空贴图高光位置一致 |
| 主光强度 | 2.0–2.5（IBL 上线后），带自阴影 |
| 环境光 | 由 PMREM 天空贴图提供，**不再用高强度半球光** |
| 补光 | 极弱，0.1–0.2，仅用于提亮机腹 |
| 阴影 | 仅战机自阴影（近距正交），不追求长投影 |
| 雾 | 指数雾，颜色取地平线色，密度让 2km 外地形接近 `#A9C6D8` |

> 参考图的"高级"来自**明暗关系干净**：一个清晰的主光、一个干净的天空、没有多余的光源干扰。相反，光越多越平。

## 4. 光效规范

### 4.1 尾焰（画面第一重心）

三层叠加，缺一层就不"贵"：

1. **核心**：近白色，`emissiveIntensity 6–8`，HDR 值 > 1，负责触发 bloom；
2. **外焰**：青蓝渐变锥，长度约核心 1.5 倍，透明度 0.6；
3. **溢光**：加法混合 sprite + 一个 `PointLight`，在机身尾部和地面上形成蓝色光斑（俯视时地面光斑必须可见，参考图 6408/6410 的辨识度全靠它）。

### 4.2 拖尾与弹道

| 类型 | 做法 |
|---|---|
| 导弹拖尾 | 沿飞行轨迹生成条带，宽度 0.15–0.3，随距离变宽，透明度 0.7→0，加法混合；带轻微弧度 |
| 机炮曳光 | 细长亮条（宽 0.05），长度 3–5 单位，白色偏暖，寿命 0.3s |
| 翼尖涡流 | 高过载时出现，宽度随过载增长，透明度 ≤ 0.25 |

### 4.3 禁止项

- ❌ 镜头光晕（lens flare）、❌ 暗角（vignette）、❌ 胶片颗粒、❌ 色差（RGB split）、❌ 重运动模糊。
- 参考图非常"干净"，这些后期特效一加就会变成廉价的"滤镜感"。

## 5. HUD 规范

现有 `css/v3.css` 是**深色玻璃面板 + 青色描边**（`rgba(8,18,32,0.88)` 底 + `#5ec8ff` 线），与参考的"透明 + 白色 + 发光"是两种语言，需要整体换皮。

| 元素 | 参考图做法 | 现状 | 动作 |
|---|---|---|---|
| 摇杆 | 大圆环（直径 ≈ 33% 屏高），径向刻度，外环带四向三角 | 小尺寸摇杆 | 放大重绘 |
| 油门 | 右侧上下两个人字箭头 | 单个"加速"按钮 | 改为上下双键 |
| 武器 | 两个圆形按钮，带刻度外环，`∞` 角标 | 方形/圆角按钮 | 改圆形 + 刻度环 |
| 顶部 | 白色展翼横条 + 盾/闪电图标 + 倒计时 | 血条 + 文字 | 重绘 |
| 底部 | 速度/高度，右下角，等宽数字 + 小图标 | 有，位置不同 | 移到右下 |
| 底板 | **几乎无底**，纯线条 + 轻发光 | 半透明深色块 | 去掉底板 |
| 描边 | 1–2px 细线，外发光 8px | 有 | 保留但改白/青 |
| 字体 | 无衬线等宽数字，字重 500 | 系统字体 | 用 DIN 类等宽 |

关键原则：**HUD 是"浮在画面上的光"，不是"贴在画面上的板"**。所有面板背景降到 ≤ 8% 不透明度，靠发光和线条立住。

## 7. 已裁决（2026-11-19）

### Q1 · 机型：先用现成隐身机，上线前换 F-16

- 参考图 6 张全是 **F-16**（单垂尾、单发、机腹进气道）。
- 项目里的 `assets/fighter.glb`（13k PBR）资产名是 `stealth-fighter`，节点含 `rudder_L/R` + `stabilator_L/R`——**双垂尾隐身战机（F-22/F-35 类）**。

**决定：原型阶段用现成隐身机（0 成本）把渲染管线跑通，上线前再换 F-16 级资产。**

> 剪影差异不影响"质感"达标，只影响"像不像这张参考图"。渲染管线与资产解耦后，换机型只是换一个 GLB + 一套材质参数，不动代码。

### Q2 · 题材与命名

**决定：命名为《中途岛1942：小宝特工》，设定为架空**——1942 的时间线与品牌名保留，装备为现代。

> 这是"架空/致敬"路线，需要在开场用一句话交代世界观（例："1942 年，一支来自未来的飞行中队降临中途岛"），否则玩家会对"1942 却开着隐身机"产生预期错位。这句话建议放在开场字幕里，成本极低但能消解全部违和感。

## 8. 验收：三张对标截图

做完后必须能与参考图并排看而不"掉档"，固定三个机位各截一张：

1. **高空云海**（对应 6406）：看天空、云、拖尾、远景空气透视；
2. **低空农田**（对应 6405）：看地形贴图质量、远景雾、机身明暗；
3. **正后俯视**（对应 6408）：看尾焰光斑、地面溢光、HUD 可读性。

判据（任一条不过即未达标）：

- 把两张图缩到 20% 大小并排，**分不出哪张是参考**（这是最狠也最准的一条）；
- 战机与背景的明度关系一致（浅灰机身 + 亮背景，不靠描边区分）；
- 尾焰在缩略图下仍是"一团发光的蓝"，而不是"一个蓝色的锥"。
