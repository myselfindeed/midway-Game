# 后期处理与调色 v1.0

> 落地时间：2026-11-19 · 对应改动：`js/v3/render/PostFX.js`、`js/v3/Game.js`、`js/v3/models.js`

## 1. 为什么必须上 composer

想让"亮的东西"发光，就得在**色调映射之前**拿到 HDR 亮度（>1.0 的那部分）。
直接渲染到屏幕时，three 在每个材质的着色器里就把亮度压进 0~1，太阳、金属高光、尾焰全被削平，
后期再怎么调也只是把整幅画糊亮。

所以改成：

```
场景 ──► HalfFloat 离屏 ──► UnrealBloom ──► OutputPass(ACES + sRGB) ──► FXAA ──► 屏幕
```

> FXAA 必须在 tone mapping **之后**：边缘检测要在感知均匀的 sRGB 空间做，
> 在线性 HDR 空间做会把高光边缘判错，出现一圈暗边。

`OutputPass` 每帧读 `renderer.toneMapping` 重建 defines，所以原来写在 renderer 上的
`ACESFilmicToneMapping` 继续生效，不用改材质。

## 2. 五个坑（都在代码注释里标了）

| # | 现象 | 原因 | 处理 |
|---|---|---|---|
| 1 | **屏幕一闪一闪**（每秒数次整帧全黑） | **HalfFloat render target + 任何 MSAA（2×/4×）都会间歇解析失败**，Chrome/Metal 下每 5~10 帧出现一次 | `samples: 0`，抗锯齿改用 FXAA |
| 2 | 显存翻几倍、画面被拉伸 | composer 把 `rt.width` 当 CSS 宽，`addPass` 又乘一次 pixelRatio | 构造后立刻 `composer.setSize(cssW, cssH)` |
| 3 | 一接后期整幅画"洗白" | ACES 内部先乘 `1/0.6 ≈ 1.67`，等于偷偷加了曝光 | `toneMappingExposure` 1.0 → **0.62** |
| 4 | 天空发灰、云失去层次 | 天空是自定义 ShaderMaterial，直出 sRGB 贴图；进 HDR 缓冲后必须显式解码 | shader 里手写 `srgbToLinear()` |

## 3. HDR 化：让什么东西真正发光

画面里必须有 >1 的像素，bloom 才有信息源。

| 物体 | 系数 | 混合 |
|---|---|---|
| 太阳（解析） | `pow(sd,3000)*16` 硬核 + `pow(sd,120)*1.0` 柔晕 | — |
| 玩家子弹 | ×3.2 | 默认 |
| 敌方子弹 | ×2.2 | 默认 |
| 机炮尾焰 | ×2.8 | Additive + depthWrite off |
| 爆炸火球 | ×2.4 | Additive |
| 护盾网纹 | ×2.4 | Additive（原有） |

系数标定基准：机身中性灰 ≈ 0.25，子弹 ≈ 3。

## 4. 参数

`js/v3/render/PostFX.js` → `PRESETS`

```js
desktop: { samples: 0, strength: 0.52, radius: 0.56, threshold: 0.95, bloomScale: 0.5 }
mobile:  { samples: 0, strength: 0.34, radius: 0.45, threshold: 1.02, bloomScale: 0.35 }
```

- **threshold 是唯一不能拍脑袋的参数**。定 0.88 时白云和海面碎高光整片被挑走，画面糊成一层白纱；
  0.95 只抓真正的 HDR 光源和太阳反光带。
- **bloom 跑半分辨率**（mobile 0.35）：bloom 是极低频信息，全分辨率纯属浪费，性能省约 4 倍。
- mobile 额外限制 pixelRatio ≤ 1.5——HalfFloat 缓冲的带宽是移动端的硬瓶颈。

## 5. 调试

```js
// 控制台（需 ?debug）
__game.postfx.setBloom(0.6, 0.6, 0.9)   // strength / radius / threshold
__game.postfx.setEnabled(false)         // 只关辉光，仍走 composer（调性不变才能对比）
__game.renderer.toneMappingExposure     // 曝光
```

URL 参数 `?bloom=0` 等价于 `setEnabled(false)`。

截图 / 体检：

```bash
node tools/shoot.mjs Docs/screenshots/x.png 2500 "<setup js>"
QUERY="bloom=0" node tools/shoot.mjs ...     # 同机位关辉光
```

## 6. 已知未解决

相机升到 90 高度朝太阳看时，云层出现巨大的斜向三角形硬边（关掉 `clouds.group` 即消失）。
怀疑是云毯 `DECK_Y = 600/720` 被相机穿越，或 billboard 跨近平面裁剪。
正常追尾视角（相机 ≈ 48）看不到，优先级低于"换 F-16 级资产"。
