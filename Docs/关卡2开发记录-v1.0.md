# 关卡 2 开发记录（岛上的风暴）

日期：2026-11-19
对应需求：《中途岛战役网页游戏_PRD_V3.4.0.md》F04 关卡表 · Demo 第 2 关
范围：关卡 2 全流程 + 关卡选择/顺序解锁。**不动画风、音效、模型**——全部复用现有资产（carrier.glb / destroyer 网格 / F-16 / 现有音效与 HUD 样式）。

## 关卡设计

**任务**：守住航母编队 → 击沉逼近的驱逐舰（PRD：守基地 + 打驱逐舰）。

| 阶段 | 内容 | 数值 |
| --- | --- | --- |
| A · 编队防空 | 敌机从外海扑向航母，绕舰投弹；玩家拦截 | 8 架（每次 2 架），单机 26 血，投弹 7 点/2.6s |
| B · 反舰突击 | 两艘驱逐舰从外海压向航母 | 各 88 血 = 一发地狱火（55×1.6），航速 7，停在航母外圈 |

- 己方航母（基地）520 血，放在滩头 (0,-18,-250)；玩家出生 (0,46,-180) 朝 +Z 面向大海——开局迎头就是来袭机群。
- 阶段 A 达成即存检查点 cp1；检查点重置 = 编队满血 + 直接进阶段 B。
- 失败条件：玩家被击落 / 编队装甲归零（各自独立文案）。

## 关键实现

- `js/v3/levels.js`（新增）：关卡表 = 纯数据（出生点、基地、波次参数、全部文案）。关卡 1 的 6/12 检查点数字保留原值。
- `Game.js`：`applyLevel(id)` + 关卡感知的 `resetToCheckpoint()`；`base` 独立于 `ships`（不会被锁定/误伤）；`updateStrikeEnemy`（直线压向 → 绕舰盘旋投弹，带侧向正弦摆动）；`updateFleetAI`（护航舰压进 + 防空）；`syncMission()` 按关卡出任务栏文案。
- 敌机投弹走 `spawnBullet(..., {base:true})`，命中判定打到 `base.hitCenter`。
- `startLevel()` 现在先 `cancelAnimationFrame` 再起循环——重复调用会叠出两条 RAF（速度翻倍）。

## 修掉的一个隐藏 bug：舰船永远锁不上

准星锁定规则是"目标投影进准星 48px 窗口"，按同高度缠斗调的；
对贴海面的舰船实测 300 单位距离 dy≈87px，`locked` 恒为 null——**地狱火的对舰 ×1.6 从来没生效过**。
改为舰船专用判定：机头指向 + ±35° 锥角 + 380 单位内即锁定（380 是导弹 4s 射程的上限外留量）。
敌机仍走原屏幕规则；关卡 1 的舰船也因此变得可锁定（与 PRD"阶段 B 可锁定舰船"一致）。

- 首页「开始任务」→ **关卡选择**（复用 panel 样式，新增 `.level-list` 少量 CSS，全部走既有 token）→ 关卡简报 → 战斗。
- 五关列表：1–2 可进，3–5「即将开放」；顺序解锁，`localStorage('midway-progress')` 持久化；`?debug` 全解锁。
- 胜利面板按关卡出文案；通关关卡 1 出「进入第 2 关」，通关关卡 2 提示 Demo 结束。

## 数值坑（记下来）

1. 来袭敌机速度不能高于玩家巡航（28）：第一次对头穿越后就永远追不上了。定 26。
2. 驱逐舰血量必须恰好 ≤ 一发地狱火（88）：22s 导弹冷却下，两发一个会让阶段 B 变成干等。
3. 敌机绕舰盘旋高度取航母甲板上方 ~34 单位，正好在玩家可以俯冲攻击的区间。

## 验证

- 无头 Chrome 全流程模拟（`/tmp/sim.mjs` 思路）：L2 开局 → 打满 8 架进 cp1 → 击沉 2 舰胜利 → cp1 重试 → 编队击沉失败面板 → 切回 L1 回归（6/12 检查点、胜利）→ 再切回 L2 清场重建。全程零控制台错误。
- 锁定几何实测：150/208/306/311 单位、±60 侧偏均锁定，424（超 380 射程）不锁。
