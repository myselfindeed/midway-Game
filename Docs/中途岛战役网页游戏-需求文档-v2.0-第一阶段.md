## 0. 本次重定位摘要（一句话）

把一款「7 岁儿童、横屏、卡通」的二战空战游戏，改造为一款「**成年玩家、竖屏触控、写实 3D 军事质感**」的二战中途岛题材游戏——**题材与历史骨架保留，画风、屏向、调性、目标用户整体转向**。

### 0.1 变更来源（用户输入）

1. 附 3 张参考图：均为**白底、写实 3D 军事载具展示渲染**（现代战斗机 / 航空母舰 / 驱逐舰），无 UI、无场景、无环境。
2. 要求统一画面风格为参考图效果。
3. 要求适配**手机竖屏**显示与**触控**操作。
4. 内容调性与视觉表达面向**成年玩家**。

### 0.2 参考图性质判断（重要，先统一认知）

> 三张参考图是「**载具资产质感**」的参照，不是「完整游戏画面」的参照。它们只说明了**单个载具要做到什么精度与写实度**，没有给出**场景、色调、UI、运镜、玩法画面**的方向。因此：
> - 第二阶段画风方案将把「载具写实质感」作为硬性方向，另行确定场景/UI/色调规则。
> - 参考图存在一个显著冲突（见 Q1）：参考图为**现代**装备（F/A-18、宙斯盾驱逐舰），而本作题材为**二战中途岛**，需先确认「借鉴质感」还是「连题材一起现代化」。

## 1. 目标用户

| 维度 | v1.1（原） | v2.0（新） | 设计含义 |
|---|---|---|---|
| 用户 | 7 岁儿童 | **成年玩家（18+）** | 去除儿童化表达与保姆式引导 |
| 兴趣画像 | 家长/老师陪同 | 历史军事题材爱好者、二战史读者、军事游戏玩家 | 重视装备还原度与历史考据 |
| 使用场景 | 家庭平板/课堂投屏/车上 | **手机竖屏、碎片时间单手/双手触控** | 一局 2–4 分钟，随手可玩 |
| 认知水平 | 无历史先备知识 | 有历史常识，能接受复杂操作与真实战争叙事 | 文案可成人化，术语可上浮 |
| 挫败耐受 | 低 | 高 | 可提高难度、允许失败与重试 |

### 1.1 使用场景（新）

| 场景 | 描述 | 要求 |
|---|---|---|
| A. 碎片时间 | 通勤/排队，单手竖屏 | 单手可玩，操作集中在屏幕下半部 |
| B. 深度体验 | 在家横握或竖握，长时间通关 | 画面质感要经得起大屏细看 |
| C. 展示分享 | 截图分享到社交平台 | 写实载具是「晒图」的核心卖点 |

## 2. 玩法范围（保留 / 调整 / 移除）

### 2.1 保留（骨架不变）

| 项 | 说明 |
|---|---|
| 五关历史框架 | 云上的眼睛 → 小岛保卫战 → 引开敌人 → 五分钟 → 最后的反击 |
| 史实映射 | 五关仍对应中途岛战役真实节点（§4 历史故事线沿用） |
| 核心战斗循环 | 接近 → 自动开火 → 击落 → 成长 |
| 基础操作模型 | 拖拽飞行 + 自动开火（无需瞄准、无需手动扣扳机） |
| 装备还原骨架 | 五类我方机 + 五类敌方舰机，保留识别特征（减速板、起落架、舰岛位置等） |

### 2.2 调整（随调性/竖屏/成人向改变）

| 项 | v1.1 | v2.0 建议 | 原因 |
|---|---|---|---|
| 难度曲线 | 儿童易通关（通关率≥80%） | 成人有挑战，重试成本可更高 | 目标用户改变 |
| 成长系统 | 7 级 RPG 式经验升级 | **简化**：保留火力/技能升级，去除「隐形难度调节」「3 次失败送僚机」等保姆辅助 | 成人看重技巧而非数值碾压（待 Q3 确认） |
| 叙事系统 | 3 张故事卡 + 历史档案 + 儿童三选一问答 | **成人化**：改为「战役简报 + 战史档案」，去除儿童问答与童声朗读（待 Q4 确认） |
| 文案 | ≤12 字/句，无军事术语 | 成人语言，术语可上浮，允许长句 | 目标用户改变 |
| 特殊能力 | 紧急闪避/全屏扫射/炸弹强化 | 保留但可重新评估手感与表现 | 待玩法评审 |

### 2.3 移除 / 重新定义（儿童向专属）

| 项 | 处理 |
|---|---|
| §11 儿童安全红线（无血/无死亡词汇/无失败羞辱） | **重新定义为「历史严肃性规范」**（见 §5） |
| 家长面板 / 家长报告 / 时长提醒 | **移除**（待 Q8 确认是否保留任何家长功能） |
| 童声朗读 / 语音开关 | 移除童声；是否保留配音待定 |
| 「再试一次」代替「失败」 | 可恢复常规「任务失败 → 重开」提示 |
| 荣誉徽章（截图给家长） | 移除或改为成就/战绩页 |

## 3. 操作方式（竖屏触控）

### 3.1 基础操作（沿用 + 竖屏化）

| 操作 | 行为 | 备注 |
|---|---|---|
| 单指按住拖动 | 飞机跟随手指（带缓动） | 竖屏下飞机默认在**屏幕下半部** |
| 松开 | 惯性滑行后悬停 | 不变 |
| 进入射程 | 自动开火 | 竖屏下前方扇形朝上 |
| 特殊能力键 | 点击触发 | 竖屏下移至**底部** |
| 投弹键 | 仅关卡 4/5，点击触发 | 竖屏下移至**底部右下** |

### 3.2 竖屏操作布局（初步建议，画风方案细化）

```
┌───────────────────┐
│  顶部状态区        │ 命数/机体强度/进度/暂停
│  (HUD 常驻)        │
│                   │
│      战斗视野       │ 敌机从上/斜上出现
│      (主区域)       │
│      玩家飞机       │ 位于屏幕下方 ~65%
│                   │
│  [特殊能力] [投弹] │ 底部操作区（手指不挡视野）
└───────────────────┘
```

### 3.3 触控约束

- 手指热区 ≥ 48×48px；操作键集中在底部 20% 区域。
- 拖拽与按键可同时（多点触控）。
- 阻止页面滚动、双击缩放、长按选中。

## 4. 画面适配（竖屏）

| 项 | 规格 |
|---|---|
| 屏向 | **竖屏 9:16**（原横屏 16:9） |
| 逻辑分辨率（建议） | **720 × 1280**（等比缩放，DPR ≤ 2x） |
| 竖屏旋转提示 | 横屏时提示「请竖屏使用」（与原逻辑相反，待 Q6 确认是否兼容横屏） |
| 视差/透视 | 斜俯视 50°–55°，海面透视、地平线位置需按竖屏重算（画风方案细化） |
| 桌面端 | 竖屏居中展示，两侧留空或加背景（待 Q6 确认） |

## 5. 内容调性（成年向 · 历史严肃性规范）

> 取代原 §11 儿童安全红线的，是面向成人玩家的**历史严肃性规范**。

| 原则 | 要求 |
|---|---|
| 尊重史实 | 装备、时间线、战役节点保持考据准确；允许出现年份、人名、番号 |
| 不美化战争 | 胜利演出克制，落在「海面平静」，不欢呼、不喊口号 |
| 真实但不猎奇 | 允许写实战损（浓烟、火光、倾斜、沉没），但**是否渲染人员伤亡/血腥**需确认（见 Q7） |
| 只讲事实与选择 | 不输出「谁是好人」的简单价值判断 |
| 成人化表达 | 文案、界面、叙事面向成年玩家，去除儿童化语气 |

## 6. 验收标准（重写 · 面向成人）

| 编号 | 验收项 | 判定标准 |
|---|---|---|
| A1 | 画面风格 | 载具达到参考图级别的写实质感（载具剪影、材质、明暗与参考图同档） |
| A2 | 竖屏适配 | 720×1280 下全界面无裁切/错位，安全区（刘海/圆角）内元素不遮挡 |
| A3 | 触控操作 | 拖拽跟手延迟 ≤ 100ms；多指同按无冲突；无页面滚动/双击缩放 |
| A4 | 玩法 | 五关可通，单关 2–4 分钟，难度对成人有挑战但不劝退 |
| A5 | 历史严肃性 | 装备与史实节点考据准确，无违背历史的情节虚构（艺术化表现除外） |
| A6 | 性能 | 中端手机（如骁龙 7 系/iPhone 12 级）稳定 ≥ 50fps |
| A7 | 离线 | 飞行模式下可完成全部五关 |
| A8 | 一致性 | 全装备同一光源/色调/描边规则，画面整体统一（详见画风方案） |

## 7. 需确认事项（逐项确认 · 本阶段核心）

> 以下每一项都直接影响第二阶段画风方案与后续开发范围，请逐项确认或给出你的选择。默认建议已标注。

### A. 题材范围

| 编号 | 问题 | 建议默认 |
|---|---|---|
| **Q1** | 题材是否**保持 1942 二战中途岛**？参考图是**现代**装备（F/A-18、宙斯盾驱逐舰），是「只借鉴写实质感」还是「连题材一起现代化」？ | **保持二战中途岛**，参考图仅取「写实 3D 质感/精度」，二战装备（SBD、零式、赤城号等）做写实化 |

### B. 玩法

| 编号 | 问题 | 建议默认 |
|---|---|---|
| **Q2** | 竖屏下核心玩法形态？(a) 沿用「拖拽飞行 + 自动开火」的斜俯视空战；(b) 改为经典竖版弹幕射击（雷电式）；(c) 其他 | **(a) 沿用**拖拽+自动开火，仅视野改竖屏 |
| **Q3** | 是否保留「成长系统（经验/升级/技能）」？成人玩家更看重技巧，数值升级会弱化挑战感 | **简化保留**：留火力/技能升级，去掉「隐形难度调节」「送僚机」等辅助 |
| **Q4** | 是否保留「故事卡/历史档案」叙事系统？ | **保留但成人化**：改为「战役简报 + 战史档案」，去除儿童问答与童声 |

### C. 视觉（第二阶段展开，此处先定调）

| 编号 | 问题 | 建议默认 |
|---|---|---|
| **Q5** | 写实 3D 的实现技术路线？(a) 预渲染序列帧（2.5D，沿用现有 Canvas 2D）；(b) 实时 WebGL/Three.js 真 3D；(c) 高精度 2D 手绘仿写实 | **(a) 预渲染序列帧**（质感好、性能稳、低端机不掉帧）；WebGL 仅脚本演出备选 |
| **Q6** | 是否**只做竖屏**，还是横竖屏都要兼容？ | **优先竖屏**，桌面端竖屏居中展示；横屏兼容列为可选 |

### D. 内容调性

| 编号 | 问题 | 建议默认 |
|---|---|---|
| **Q7** | 成人向战损表现的边界？(a) 允许写实爆炸/火光/沉没，含人员伤亡暗示；(b) 写实战损但**不渲染血腥/人体**，克制呈现代价；(c) 尽量轻量（接近现状，仅写实化外观） | **(b)** 历史严肃、写实战损，但不刻意渲染血腥/人体 |
| **Q8** | 是否完全移除「家长面板/时长提醒」等儿童向功能？ | **移除**（如确需可加一个简单的设置页） |

### E. 范围 / 交付

| 编号 | 问题 | 建议默认 |
|---|---|---|
| **Q9** | 本次重做范围？(a) 复用现有玩法与关卡逻辑，**重点重构美术渲染层 + UI/布局**；(b) 整体重构（含玩法） | **(a) 复用逻辑、重构画面**，降低风险、缩短工期 |

## 8. 影响范围小结（v1.1 → v2.0）

| 变更点 | v1.1 | v2.0 | 影响模块 |
|---|---|---|---|
| 目标用户 | 7 岁儿童 | 成年玩家 | 文案、难度、叙事 |
| 屏向 | 横屏 16:9 | 竖屏 9:16 | UI 布局、镜头、操作布局 |
| 画风 | 仿 3D 厚描边卡通 | 写实 3D 军事质感 | 美术渲染层整体重做 |
| 内容红线 | 儿童安全红线 | 历史严肃性规范 | 特效、战损表现、文案 |
| 成长/叙事 | RPG 升级 + 儿童问答 | 简化成长 + 成人化叙事 | 数值、关卡脚本 |
| 家长功能 | 家长面板/报告/提醒 | 移除 | UI |
| 技术路线 | 预渲染序列帧 | 预渲染序列帧（倾向不变） | 美术管线升级 |
