# 中途岛：小宝特工空战

一款基于 [three.js](https://threejs.org/) 的轻量 3D 飞行射击网页游戏，以 1942 年中途岛海战为背景，用现代空战形式进行作战推演。共 5 个关卡，顺序解锁，纯前端实现，无后端依赖。

## 玩法

| 关卡 | 标题 | 玩法 |
|------|------|------|
| 1 | 云上的眼睛 | 侦察护航：击落来袭敌机 |
| 2 | 岛上的风暴 | 编队防空 + 反舰突击：守住己方航母，击沉敌驱逐舰 |
| 3 | 勇敢的诱饵 | 牵制与牺牲：存活 90 秒 |
| 4 | 决定性的五分钟 | 突破护航，俯冲击沉敌方航母 |
| 5 | 最后的反击 | 清剿残存航母群 |

关卡进度保存在浏览器本地（`localStorage`），通关自动解锁下一关。

## 技术栈

- **three.js**（ES Module，通过 `importmap` 引入，本地 `vendor/` 目录，不依赖外网 CDN）
- 原生 HTML / CSS / JavaScript（ES Module），**无框架、无构建工具、无需安装依赖**
- 移动端优先：虚拟摇杆 + 触屏按钮，同时支持键鼠

## 快速开始

项目使用 ES Module + `importmap`，**必须通过 HTTP 服务器访问**，直接双击 `index.html` 会因模块加载失败而黑屏。

任意静态服务器即可，例如：

```bash
cd /path/to/midway-Game
python3 -m http.server 8901
```

然后浏览器打开 <http://127.0.0.1:8901/>。

## 操作说明

**触屏**：左手摇杆转向，右手按住「射击」「加速」，点按「导弹」「护盾」。

**键鼠**：

| 按键 | 功能 |
|------|------|
| `W` `A` `S` `D` / 方向键 | 转向 |
| `空格` | 机关枪射击 |
| `Shift` | 加速 |
| `E` | 地狱火导弹 |
| `Q` | 护盾 |

> 横屏体验更佳。竖屏锁定下打开游戏，画面会以横屏内容侧向显示，横放手机（顶部朝左）即可转正游玩。

## 调试参数

| 参数 | 作用 |
|------|------|
| `?debug` | 解锁全部关卡，并在控制台暴露 `window.__game` 调试对象（数字键 `1`/`2` 可试听导弹 / 爆炸音效） |
| `?level=N` | 直达第 N 关（`N` 为 1–5），跳过关卡选择与简报 |

例如：`http://127.0.0.1:8901/?debug&level=2`

## 部署

纯静态项目，部署到任意静态服务器即可。建议缓存策略：`index.html` 不缓存，模型 / 贴图 / 音频等大资产设置较长缓存（如 7 天）。

当前线上地址：<http://8.162.0.135:8083/>（Nginx，`root` 指向项目目录）。
